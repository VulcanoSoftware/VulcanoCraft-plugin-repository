             Hoe activeer je deze Configurator op GitHub Pages?
          

          

            
Omdat deze pagina volledig statisch is (HTML/CSS/JS in de /docs map), kun je hem eenvoudig gratis hosten via GitHub Pages:

            

              

                

                  
1. Push naar GitHub

                  
Zorg dat de /docs map aanwezig is in de main branch van je GitHub repository.

                

              

              

                

                  
2. Schakel Pages in

                  
Ga in je GitHub repository naar Settings → Pages.

                

              

              

                

                  
3. Selecteer Map /docs

                  
Kies bij Source Deploy from a branch, selecteer de main branch en kies de map /docs.

                

              

            

            

               Zodra je op Save drukt is jouw generator binnen 1-2 minuten online via https://<username>.github.io/<repository>/.
